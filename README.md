# workplace-mean-meme

将人像制作成身份可辨、动作鲜明、有图文反差的真人中文表情包的 Agent Skill。

## 特点

- 默认随机创作 **4 张独立的 1:1 表情包**，支持指定数量。
- 主题覆盖社交、吃瓜、嘴硬、摆烂和职场，不固定轮播四种模板。
- 保留人物辨识度；真人头肩、头颈、躯干与四肢比例为硬性验收项。
- 支持仅写文案、指定文案、局部修改；修改技能本身不会触发生图。

## 安装到 Codex

将本仓库下载到技能目录（若已有同名技能，请先备份再更新）：

```bash
git clone https://github.com/1NWZ/workplace-mean-meme.git "${CODEX_HOME:-$HOME/.codex}/skills/workplace-mean-meme"
```

## 使用

上传你有权使用的肖像，并输入：

```text
使用 $workplace-mean-meme，帮我生成表情包。
```

也可以说“生成一张吃瓜表情包”“只给我十句文案，不出图”或“只修改第二张的文字”。

## 运行要求

需要支持 SKILL.md 的 Agent，以及可用的图像生成/编辑工具。此仓库是提示与工作流规则，不是独立图像模型或可执行应用。没有图像工具时，只能提供创意和提示词。生成服务的使用权限、费用及条款由服务提供方决定。

## 参考素材与隐私

公开版只提供文字参考，不包含来源授权未确认的第三方图片、私人肖像、历史生成作品或聊天记录。没有风格参考图片也可按文字说明生成；可自行提供有权使用的参考图。身份图与风格参考必须分开，不借用参考演员五官。

## 文件结构

- `SKILL.md`：入口、创作流程、默认四张及真人比例要求。
- `agents/openai.yaml`：技能界面元数据。
- `references/`：文案、场景、风格、多样性与验收说明。

## 验证与限制

发布包已检查本地文件引用与默认规则。规则不能保证每次生成都准确，仍需逐张检查人物辨识度、人体比例、文字与肢体；不通过时修正或明确说明。验收用例见 [evaluation.md](references/evaluation.md)。
