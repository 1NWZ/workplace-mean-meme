# 文字风格参考：40 种表演与图文关系

本文件保留文字观察编号，用于解释表演、场景和图文关系；公开版不分发第三方原图及其文件清单。09=01、10=06、13=04、22=16；34 与 35 的描述相同，重复样本不增加风格权重。编号不是可加载的图片文件。

## 定义风格的九个维度

| 维度 | 从参考观察到什么 | skill 中如何使用 |
|---|---|---|
| 人物身份 | 真人表情比完美长相重要，图 01/05 的特写特别鲜明 | 本人辨识优先，允许表情与肢体变形，不变成另一张脸 |
| 表情 | 假笑、侧眼、疲惫、宕机、认真发疯并存 | 克制脸同样可以配强动作，不强制每张张嘴喊叫 |
| 动作 | 抓头、扶墙、捏鼻梁、转身逃、合十 | 提示词描述关节、手和视线位置，避免只写“搞笑” |
| 场景 | 办公室、楼梯、普通室内、户外随拍、纯合成背景 | 职场感可由文案和道具表达，不必所有图片坐在工位 |
| 造型道具 | 面膜、西装、纸巾、加载图标、翅膀、工程车 | 一张一个主梗，道具服务于文案潜台词 |
| 构图 | 紧裁大头、尴尬截帧、偏心主体、分身重复 | 缩略图可读；重复人物是有意拼贴，不是身体变异 |
| 色彩光线 | 冷青、暖黄、灰紫、桃粉分别属于不同家族 | 风格家族独立选择，不总结成唯一蓝色滤镜 |
| 画质 | 截屏感、柔糊、JPEG 转存、局部过曝、运动拖影 | 保脸与字，避免全图均匀马赛克或专业精修 |
| 文案图文关系 | 礼貌反话、自嘲防御、成句改字、谐音具象化 | 口气平，结尾转；画面补充一层意思，避免只是配图复述 |

## 这套风格的核心

“可辨识的本人 × 不体面的动作/状态 × 一本正经的短句 × 旧聊天图片的表面质感”。四者可以分别调整，不要求每张都最疯最糊。更接近这组参考的方向是“我已被职场折叠，但还保留礼貌格式”，而不是持续愤怒、脏话堆叠或精美商业恶搞海报。

图 01–22 的大喊、冲撞和崩溃提供视觉能量；图 23–40 的短句提供更轻的语言力度。合成这两部分时，应让其中一方收住：强动作配淡文案，克制动作配尖一点的反转。

## 从分析到成片的例子

- 图 01 的职业假笑 + 图 30 的礼貌否定机制 → 本人端着文件侧眼笑，配新句“态度很好，意愿没有”。
- 图 02 的坐瘫抓头 + 图 29 的进度安抚机制 → 本人在楼梯抱头但面孔可见，配新句“在处理了，先处理心情”。
- 图 19 的粉色双曝光 + 图 32 的对称反击 → 本人合十假笑，背景同人的疲惫虚影，配新句“感谢理解，虽然你没有”。
- 图 21 的加载符号 + 图 24 的逻辑矛盾 → 本人呆坐，配新句“对齐了，都没想法”。
