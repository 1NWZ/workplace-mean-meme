# 生成与修订

## 镜头卡与提示词

镜头卡只为规划，不是工具参数。精简记录：用途/机制、精确文字、身份锚点、表情、主动作、道具、场景、造型、镜头、字样、参考角色、最近作品差异。

实际提示按以下顺序组织：
1. 生成或局部编辑；本轮肖像身份锚点，逐图分配角色。
2. 完整场景中一个正在发生的笑点。具体描述眉眼嘴与动作，不只写“搞笑”。
3. 摄影距离和裁切，正常头肩关系，动作必要的肩肘腕连接。每只手一个任务。
4. 选定家族的色调与 Q2 质感；身份与字比粗糙优先。
5. 准确文案、断行、位置、样式；禁额外字和水印。
6. 本图的关键避免项。不要堆一整页重复否定使主动作被淹没。

只输入必要参考；不用固定英文范文让每张默认 chest-up、tiny smile、warm yellow、white black outline。

## 定点修订

| 反馈 | 调整 | 保留 |
|---|---|---|
| 不像 | 原始肖像优先、减少脸部变形、检查混脸 | 梗、已认可场景 |
| 头大 | 修真实相机透视和头肩关系 | 原景别的意图，不自动全改远景 |
| 多余肢体 | 清楚分配每臂任务，修肩肘腕连接；必要时去掉一个互斥动作 | 表演强度，不全部改手垂下 |
| 甩头假 | 明确身体先转、头与肩有限角度差、头发根部随头且发梢滞后；冻结一个时刻 | 动态意图；不能只画一团横飞头发 |
| 太端着 | 换成动作中间帧、嘴硬破功、张嘴抬眉等 | 身份与正常身体比例 |
| 不够 mean | 换反转或责任回推，不只换辱骂词 | 用户限定的其他维度 |
| 不抽象 | 让图中物件参与语义或形成自我矛盾 | 口语可懂 |
| 太糊 | 恢复五官字形、保留细节选择性损失 | 偏色与旧截图质感 |
| 太像上一张 | 比较机制与表演再换方案 | 身份和接受的质感 |
| 只换字 | 引用成片仅编辑指定文字 | 全部已认可画面，检查编辑漂移 |

候选讨论不必调用生成工具。明确选句或要求修改成片时直接编辑。明显生成错误定点重试一次，仍失败如实说明，不把失败版包装成完美通过。
